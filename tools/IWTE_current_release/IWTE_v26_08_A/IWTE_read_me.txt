INTEGRATED WORLD TERRAIN EDITOR and Battle Model Editor

Current version is IWTE_v26_08_A from August 26th 2026.

We suggest you always keep a copy of the prior version as backup .. in case of any bugs.

This is a release of the INTEGRATED WORLD TERRAIN EDITOR (which basically edits a lot of the rome/m2tw and some rome remastered files). 
This has expanded quite a lot since it started and should now handle items such as :
1. Texture conversions
2. M2TW world settlements and other miscellaneous terrain and battlemap features.
3. M2TW unit and strat models together with animations for editing via Blender (or a version of 3dsmax with the appropriate collada/GLTFv2 interface).
4. RTW/RR unit and strat models together with animations for editing via Blender (or a version of 3dsmax with the appropriate collada/GLTFv2 interface).
5. Simplified strat map editing functions
6. M2TW modeldb to CSV
7. Rome Remastered map mesh and texture creation 
8. Rome remastered settlement plan editing

Most newer functions are added as action items from the top line of menus rather than the button process which are mostly related to world/terrain type items.

When running IWTE it is advised to run it within a simple bat file containing :
IWTE_v26_08_A.exe (or the version of the exe you are running)
cmd /k
This will keep the console window open in the event of a crash and provde some messages on the cause.
